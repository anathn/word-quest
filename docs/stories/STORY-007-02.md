## Overview

Display a collection of achievement badges that students have earned throughout their journey. This visual celebration of accomplishments provides motivation and a sense of pride.

## User Story

As a student, I want to see all the badges I've earned so that I can feel proud of my achievements and track my progress.

## Acceptance Criteria

### Functional Requirements

- [ ] Display all earned badges in a grid or collection view
- [ ] Show badges with hover/click animations to highlight them
- [ ] Display badge name and brief description on hover
- [ ] Show unearned badges with locked/grayed appearance
- [ ] Count total badges earned (e.g., "12/25 Badges")
- [ ] Highlight newly earned badges with animation
- [ ] Organize badges by category (speed, accuracy, perseverance)
- [ ] Allow filtering by category or showing all

### Non-Functional Requirements

- [ ] Badge icons load within 200ms
- [ ] Smooth animations at 60 FPS
- [ ] Keyboard accessible (tab through badges)
- [ ] Responsive layout for different screen sizes
- [ ] Accessibility: Screen reader announces badge names

class BadgeManager:
    def __init__(self, progress_data):
        self.progress = progress_data
        self.badges = self.load_badge_definitions()
        self.earned = self.progress.earned_badges
    
    def load_badge_definitions(self):
        """Load all badge definitions from config"""
        return [
            BadgeData("first_planet", "First Steps", "Complete your first planet"),
            BadgeData("streak_10", "On Fire!", "Get 10 correct in a row"),
            BadgeData("perfect_word", "Sharp Shooter", "Spell 50 words correctly first try"),
            # ... more badges
        ]
    
    def check_unlocks(self):
        """Check if any new badges should be unlocked"""
        new_unlocks = []
        for badge in self.badges:
            if badge.id not in self.earned and badge.criteria_met(self.progress):
                self.earned.append(badge.id)
                new_unlocks.append(badge)
                self.progress.save()
        return new_unlocks
    
    def get_badges_by_category(self, category):
        """Filter badges by category"""
        return [b for b in self.badges if b.category == category]

class BadgeCollection:
    def __init__(self, screen, badge_manager):
        self.screen = screen
        self.manager = badge_manager
        self.selected_badge = None
        self.layout = self.calculate_grid_layout()
    
    def calculate_grid_layout(self):
        """Calculate badge positions in grid"""
        cols = 5
        spacing = 100
        start_x = 100
        start_y = 150
        layout = []
        
        for i, badge in enumerate(self.manager.badges):
            col = i % cols
            row = i // cols
            x = start_x + (col * spacing)
            y = start_y + (row * spacing)
            layout.append((x, y, badge))
        
        return layout
    
    def handle_input(self, event):
        """Handle selection of badges"""
        if event.type == pygame.MOUSEBUTTONDOWN:
            clicked = self.get_clicked_badge(event.pos)
            if clicked:
                self.selected_badge = clicked
                self.play_hover_sound()
        
        elif event.type == pygame.KEYDOWN:
            if event.key == pygame.K_RIGHT:
                self.select_next_badge()
            elif event.key == pygame.K_LEFT:
                self.select_previous_badge()
    
    def draw(self):
        """Render badge collection"""
        self.draw_background()
        for x, y, badge in self.layout:
            state = "earned" if badge.id in self.manager.earned else "locked"
            badge_card = BadgeCard(badge, state, (x, y))
            badge_card.draw(self.screen)
            
            if self.selected_badge == badge:
                self.draw_selection_ring(x, y)
        
        self.draw_total_count(len(self.manager.earned), len(self.manager.badges))

class BadgeCard:
    def __init__(self, badge_data, state, position):
        self.badge = badge_data
        self.state = state  # "earned" or "locked"
        self.position = position
        self.image = self.load_image()
        self.is_hovered = False
    
    def load_image(self):
        """Load appropriate badge image based on state"""
        if self.state == "locked":
            return load_image(f"assets/badges/locked.png")
        return load_image(f"assets/badges/{self.badge.id}.png")
    
    def draw(self, screen):
        """Draw badge card"""
        # Apply opacity for locked badges
        if self.state == "locked":
            self.image.set_alpha(128)
        else:
            self.image.set_alpha(255)
        
        screen.blit(self.image, self.position)
        
        if self.is_hovered and self.state == "earned":
            self.draw_tooltip(screen)

## UI/UX Requirements

### Screens Involved

- **Badge Collection Screen**: Accessible from Space Map or Student Progress screen

### User Interactions

1. Student sees grid of badges (earned and locked)
2. Hover/click on earned badge shows details
3. Student can navigate using arrow keys

### Visual Design Notes

- Grid layout with consistent spacing (80px badges, 20px gaps)
- Earned badges: Full color, slight glow
- Locked badges: Desaturated gray, lock icon overlay
- Selection ring: Animated pulsing gold ring
- Tooltip: Rounded bubble with badge name (bold 20pt) and description (regular 16pt)
- Background: Space themed, maybe showcase featuring achievements
- Category tabs at top: "Speed", "Accuracy", "Perseverance", "All"
