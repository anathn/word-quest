## Overview

Persist progress after every completed spelling word and resume an interrupted
planet at the next unfinished word.

## User Story

As a student, I want my work saved after every word so that a crash or power
loss does not make me repeat completed work.

## Acceptance Criteria

- [x] Save the active session and planet after each completed word.
- [x] Preserve the exact planet word order and completed results.
- [x] Restore the unfinished session after restarting the game.
- [x] Resume at the next unfinished word.
- [x] Clear the checkpoint after a planet and session are safely saved.
- [x] Preserve existing sessions and achievements during partial updates.
- [x] Write progress atomically to avoid partial JSON files.
- [x] Include automated checkpoint, restore, and completion tests.

## Technical Implementation

- `ProgressTracker` owns the active checkpoint and merges it into the
  canonical progress document.
- `SessionTracker` restores unfinished session summaries.
- `PlanetManager` restores completed results and the next word index.
- `SpellingChallengeScreen` uses sequential planet words instead of random
  global selection.
- `DataStore` writes to a temporary file and atomically replaces the target.

## Implementation Notes

Checkpoints intentionally exclude an unfinished word. A crash during a word
therefore resumes that same word, while a crash after a completed word resumes
the following word.
