## Overview

Ship enough built-in spelling content for a fresh installation to play one
complete 12-planet galaxy without requiring a CSV import.

## User Story

As a student, I want ready-to-play spelling words so that I can begin an
adventure immediately after setup.

## Acceptance Criteria

- [x] Bundle 60 spelling words across 12 five-word planets.
- [x] Provide four difficulty levels with 15 words each.
- [x] Include a definition and context sentence for every word.
- [x] Reduce starter-letter assistance as difficulty increases.
- [x] Load bundled content through the normal `WordManager` path.
- [x] Verify planet IDs, counts, difficulty distribution, and starter hints.

## Technical Implementation

The canonical bundled content remains `src/data/word_lists.json`. Difficulty
levels use starter-letter counts of 3, 2, 1, and 0 respectively. Parent-managed
lists under `data/word_lists/` remain optional custom content and are not
required for first play.

## Implementation Notes

The repository already contained 15 playable words, despite the empty
parent-managed list directory. This story expands that canonical gameplay file
to the PRD target rather than duplicating it elsewhere.

Implementation completed 2026-11-22. The bundled list now contains exactly 15
words at each of four difficulty levels.
