## Overview

Create a visual space map that shows students their journey through the game, displaying which planets they've visited, completed, and unlocked. This provides a sense of exploration and accomplishment.

## User Story

As a student, I want to see a visual map of my space journey so that I can see how far I've traveled and what I've achieved.

## Acceptance Criteria

### Functional Requirements

- [ ] Display a space-themed map with planets arranged in a path
- [ ] Show visited planets with distinct visual state (visited vs. unvisited)
- [ ] Show completed planets with "bloomed" or special appearance
- [ ] Display current planet location with rocket indicator
- [ ] Unlock future planets progressively (grayed out or hidden until unlocked)
- [ ] Allow clicking on visited planets to view details
- [ ] Show solar system and galaxy boundaries visually
- [ ] Animate rocket movement when transitioning between planets

### Non-Functional Requirements

- [ ] Load map within 500ms
- [ ] Maintain 30+ FPS during any animations
- [ ] Responsive to different screen sizes
- [ ] Kid-friendly icons and colors (large touch targets 64px+)
- [ ] Accessibility: keyboard navigation to select planets

```python
class SpaceMap:
    def __init__(self, screen, progress_data):
        self.screen = screen
        self.progress = progress_data
        self.planets = self.load_planets()
        self.current_position = self.get_current_position()
    
    def load_planets(self):
        """Load all planets and their states based on progress"""
        planets = []
        for planet in all_planets:
            state = self.determine_planet_state(planet)
            planets.append(PlanetNode(planet, state))
        return planets
    
    def determine_planet_state(self, planet_id):
        """Determine if planet is locked, visited, or completed"""
        if planet_id in self.progress.completed_planets:
            return "completed"
        elif planet_id in self.progress.visited_planets:
            return "visited"
        elif self.is_unlocked(planet_id):
            return "current"
        return "locked"
    
    def handle_input(self, event):
        """Handle mouse clicks and keyboard navigation"""
        if event.type == pygame.MOUSEBUTTONDOWN:
            clicked = self.get_clicked_planet(event.pos)
            if clicked and clicked.state != "locked":
                self.show_planet_details(clicked)
    
    def draw(self):
        """Render the complete space map"""
        self.draw_starfield()
        self.draw_path()
        for planet in self.planets:
            planet.draw(self.screen)
        self.draw_current_indicator()

class PlanetNode:
    def __init__(self, planet_data, state):
        self.id = planet_data.id
        self.name = planet_data.name
        self.position = planet_data.coordinates
        self.state = state  # "locked", "visited", "completed", "current"
        self.sprites = self.load_sprites()
    
    def draw(self, screen):
        """Draw planet with state-appropriate appearance"""
        sprite = self.sprites[self.state]
        screen.blit(sprite, self.position)
        if self.state != "locked":
            self.draw_name_label(screen)
```

## UI/UX Requirements

### Screens Involved

- **Space Map Screen**: Full-screen map view accessible from main menu

### User Interactions

1. Student clicks/keys to select a visited planet
2. System shows planet details (name, words mastered, accuracy)
3. Student clicks "Return" to go back to map
4. Rocket indicator pulses at current location

### Visual Design Notes

- Deep blue background (#1a1a3e) with twinkling stars
- Planet colors vary by completion state:
  - Locked: Dark gray, locked icon overlay
  - Visited: Actual color, slightly dimmed
  - Completed: Bright color with sparkle/bloom effect
  - Current: Pulsing glow effect
- Path between planets: glowing white line with subtle animation
- Rocket indicator: animated with engine flames
- Font: Rounded, friendly font at 24pt minimum
